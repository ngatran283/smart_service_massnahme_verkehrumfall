# smart_service_massnahme_verkehrumfall
Einen Smart Service, der Unfalldaten analysiert und die Bedingungen identifiziert, unter denen schwere Unfälle entstehen.  Daraus leitet der Service priorisierte Maßnahmen ab: für die Verkehrsbehörde im Bereich Infrastruktur und für die Verkehrspolizei im Bereich Kontrollen. So kann die Stadt ihr begrenztes Budget dort einsetzen.
